## 01 · Profile

I am a **Software Engineering undergraduate at Pujiang Institute, Nanjing Tech University**, working on **computer vision, deep learning, and intelligent systems**.

My work spans visual perception, medical imaging, multi-object tracking, traffic forecasting, privacy-preserving spatiotemporal analytics, decision intelligence, and research-oriented software engineering. I care about more than benchmark accuracy: a useful system should also be **efficient, reproducible, interpretable where possible, and deployable in practice**.

`Research → Implementation → Evaluation → System`

## 03 · Selected Systems

<table>
<tr>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/DynaFlux">DynaFlux</a>
**Multi-Scale Dynamic Graph Learning for Traffic Flow Forecasting**

Multi-period temporal encoding, global flow similarity, local road topology, graph fusion, and gated dilated temporal modeling in one PyTorch forecasting pipeline.

<sub>PyTorch · Dynamic Graphs · GAT · Temporal Modeling</sub>

</td>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/AMFTrack">AMFTrack</a>
**Adaptive Motion-Feature Tracking**

A modular pedestrian MOT system combining detection, ReID, adaptive motion estimation, geometry-aware association, trajectory features, and Hungarian matching.

<sub>YOLOv8 · OSNet · Kalman Filter · MOT</sub>

</td>
</tr>

<tr>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/M2KT">M2KT</a>
**Multi-Modal Knowledge Transfer for Radiology Report Generation**

A radiology report generation framework with learned knowledge memory, multimodal alignment, evidence grounding, ontology reasoning, iterative refinement, and temporal progression modeling.

<sub>Medical AI · Transformer · Multimodal Learning · GNN</sub>

</td>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/PAP-Age-Recognition">PAP-Age</a>
**Personalized Aging-Pattern Facial Age Estimation**

Models both static facial appearance and identity-level chronological aging trajectories using CNN representation, PCA projection, LSTM temporal modeling, and attention.

<sub>Inception-v4 · PCA · LSTM · Attention</sub>

</td>
</tr>

<tr>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/STARB-DP">STARB-DP</a>
**SpatioTemporal Adaptive Release-Budget Differential Privacy**

A privacy-preserving streaming publication framework with temporal windows, local spatial constraints, adaptive budget allocation, private change evaluation, and selective release.

<sub>Differential Privacy · Spatiotemporal Data · Streaming Analytics</sub>

</td>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/stamp-hf-correlation-topsis">STAMP-HF TOPSIS</a>
**Risk-Adaptive Hesitant Fuzzy Interactive Decision Analysis**

Combines STAMP-informed indicator construction, risk-adaptive HFE completion, sparse 2-additive interaction capacity, robust TOPSIS, and Monte Carlo uncertainty propagation.

<sub>Decision Intelligence · Fuzzy Systems · Robust Ranking</sub>

</td>
</tr>

<tr>
<td width="50%" valign="top">

### <a href="https://github.com/ZJY-HSBL/ScolioVision">ScolioVision</a>

A research-oriented software platform for radiograph preprocessing, model-service integration, structured Cobb-angle workflows, history management, and rehabilitation interaction.

<sub>Medical Imaging · Web Engineering · Model Integration</sub>

我是南京工业大学浦江学院软件工程专业本科生，主要关注 **计算机视觉、深度学习与智能系统**。

目前的研究与项目覆盖目标检测、图像分割、多目标跟踪、医学影像分析、交通流量预测、时空数据隐私保护、多属性决策分析以及科研软件系统开发。

我更关注“算法—实验—系统”之间的完整链路：不仅追求模型精度，也关注计算效率、实验可复现性、工程可维护性以及最终的系统落地。

当前代表性方向包括：

- **视觉智能：** AMFTrack、PAP-Age；
- **医学 AI：** M2KT、ScolioVision；
- **时空智能：** DynaFlux；
- **可信决策与隐私：** STARB-DP、STAMP-HF TOPSIS；
- **软件工程：** FolderBox 及其他研究型原型系统。
