## About · 关于我

你好，我是**海生不浪**。主要关注**计算机视觉、深度学习与智能软件系统**，重视实验可复现性与工程实现。希望把研究中的方法，转化为清晰、可靠、可用的软件。

I work on **computer vision, deep learning, and intelligent software systems**, with an emphasis on reproducible experiments and practical engineering.

<a name="research"></a>

## Research · 研究方向

- **视觉感知 / Visual Perception** — 目标检测、多目标跟踪与轻量化视觉模型。
- **医学 AI / Medical AI** — 医学影像分析，以及检测与分割方法。
- **时空学习 / Spatiotemporal Learning** — 动态图建模与交通流预测。

> **在研 / Ongoing** · 多模态 MRI 脑肿瘤病灶检测与分割研究。<br>
> Multimodal MRI brain-tumor detection and segmentation.
